---
title: "Limites de requisição"
description: "Quantas requisições por minuto cada token pode fazer."
---

Os limites são contados **por token**, em janelas de 1 minuto:

| Categoria | Rotas | Limite |
| --- | --- | --- |
| Envio de mensagens | `POST /v1/{phone_number_id}/messages` | 500 req/min |
| Upload de mídia | `POST /v1/{phone_number_id}/media` | 60 req/min |
| Consultas | Todas as outras | 60 req/min |

Quando o limite é excedido, a API retorna **`429 Too Many Requests`**, com uma mensagem indicando quantos segundos aguardar:

```json
{
  "statusCode": 429,
  "message": "Rate limit excedido (60 req/min). Tente novamente em 12s."
}
```

<Tip>
  Evite consultar o mesmo recurso em loop, como o status do número ou a lista de templates. Para acompanhar mudanças, use os [webhooks](/api-reference/whatsapp/webhooks/receber-eventos).
</Tip>
