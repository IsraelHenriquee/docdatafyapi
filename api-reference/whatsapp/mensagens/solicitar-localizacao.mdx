Envia uma mensagem com um texto e um **botão para o cliente compartilhar a localização**. É útil para calcular frete, indicar a unidade mais próxima ou confirmar um endereço de entrega. A [janela de 24 horas](/api-reference/whatsapp/mensagens/introducao#janela-de-24-horas) precisa estar aberta.

<Note>
  O destinatário pode ser informado pelo **número de telefone** (`to`) ou pelo **ID do usuário** (`recipient`). Se os dois forem enviados, vale o `to`; para enviar pelo ID do usuário, deixe o `to` em branco. Veja a diferença em [Destinatário](/api-reference/whatsapp/mensagens/introducao#destinatário).
</Note>

## Como montar o pedido

O pedido é uma mensagem interativa. Além do destinatário, ela tem só três partes:

| Campo | Valor |
| --- | --- |
| `interactive.type` | Sempre `location_request_message`. |
| `interactive.body.text` | Texto do pedido, com até **1.024 caracteres**. Pode conter URLs. |
| `interactive.action.name` | Sempre `send_location`. |

Ao tocar no botão, o cliente abre a tela do WhatsApp para escolher e enviar a localização.

No **Testar**, o texto do pedido já vem preenchido. Troque pelo texto que faz sentido para o seu atendimento.

## Resposta do cliente

Quando o cliente compartilha a localização, ela chega pelo [webhook](/api-reference/whatsapp/webhooks/eventos/mensagens) como uma mensagem do tipo `location`. O campo `context.id` aponta para o pedido que você enviou:

```json
{
  "object": "whatsapp_business_account",
  "entry": [
    {
      "id": "234567890123456",
      "changes": [
        {
          "value": {
            "messaging_product": "whatsapp",
            "metadata": {
              "display_phone_number": "5541999999999",
              "phone_number_id": "123456789012345"
            },
            "contacts": [
              {
                "profile": {
                  "name": "Camila Souza"
                },
                "wa_id": "5511999999999",
                "user_id": "BR.13491208655302741918"
              }
            ],
            "messages": [
              {
                "context": {
                  "from": "5541999999999",
                  "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNFQjA="
                },
                "from": "5511999999999",
                "from_user_id": "BR.13491208655302741918",
                "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjJBQjE=",
                "timestamp": "1757955600",
                "location": {
                  "address": "Av. Paulista, 1578 - Bela Vista, São Paulo - SP",
                  "latitude": -23.561414,
                  "longitude": -46.655881,
                  "name": "MASP"
                },
                "type": "location"
              }
            ]
          },
          "field": "messages"
        }
      ]
    }
  ]
}
```

`latitude` e `longitude` sempre chegam. `name` e `address` só aparecem se o cliente escolher compartilhar um local com nome.

Veja mais detalhes na [documentação de pedido de localização da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/location-request-messages).
