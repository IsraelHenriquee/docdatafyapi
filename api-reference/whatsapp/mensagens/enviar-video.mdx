Envia um vídeo, com legenda opcional, para um cliente com a [janela de 24 horas](/api-reference/whatsapp/mensagens/introducao#janela-de-24-horas) aberta.

<Note>
  O destinatário pode ser informado pelo **número de telefone** (`to`) ou pelo **ID do usuário** (`recipient`). Se os dois forem enviados, vale o `to`; para enviar pelo ID do usuário, deixe o `to` em branco. Veja a diferença em [Destinatário](/api-reference/whatsapp/mensagens/introducao#destinatário).
</Note>

## Link ou ID da mídia

Informe o vídeo de uma das duas formas:

| Campo | Quando usar | Como conseguir |
| --- | --- | --- |
| `video.link` | O vídeo está em uma URL pública. | Envie o arquivo na aba **Mídias** do número, no [painel da Datafy](https://app.datafyapi.com.br). O link gerado vale por **30 dias**. |
| `video.id` | Você já enviou o arquivo para a Meta. | Use o `id` retornado pelo endpoint [Upload de mídia](/api-reference/whatsapp/proxy/upload-de-midia). |

<Warning>
  **Envie apenas um dos dois.** Com `link` e `id` na mesma requisição, a Meta recusa o envio.
</Warning>

Para vídeos, a Meta recomenda usar o `id`, porque o envio fica mais rápido do que baixar o arquivo por link a cada mensagem.

No **Testar**, o `link` já vem preenchido com um vídeo de exemplo. Para testar com um `id`, apague o `link` antes de enviar.

## Formatos aceitos

| Formato | Extensão | Tipo MIME | Tamanho máximo |
| --- | --- | --- | --- |
| MP4 | `.mp4` | `video/mp4` | 16 MB |
| 3GPP | `.3gp` | `video/3gpp` | 16 MB |

O vídeo precisa usar o codec **H.264**, com perfil **Main** ou **Baseline**, e o áudio precisa ser **AAC** com no máximo uma faixa. Vídeos com perfil High e B-frames podem não reproduzir no WhatsApp para Android.

<Tip>
  Se o vídeo não reproduzir, converta com o ffmpeg para o formato recomendado:

  ```bash
  ffmpeg -i entrada.mov -c:v libx264 -profile:v main -c:a aac -movflags +faststart saida.mp4
  ```

  O `-movflags +faststart` coloca as informações do vídeo no início do arquivo, como a Meta recomenda.
</Tip>

A legenda aceita até **1.024 caracteres** e a mesma [formatação do texto](/api-reference/whatsapp/mensagens/enviar-texto#formatação).

Veja mais detalhes na [documentação de mensagens de vídeo da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/video-messages).
