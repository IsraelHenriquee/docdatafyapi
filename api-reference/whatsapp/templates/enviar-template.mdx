---
title: "Enviar template"
api: "POST /v1/{phone_number_id}/messages"
---

Use `type: "template"` para iniciar ou retomar uma conversa quando a [janela de 24 horas](/guias/whatsapp/conceitos/janela-de-24-horas) está fechada. O template precisa estar **aprovado pela Meta**.

```json
{
  "messaging_product": "whatsapp",
  "to": "5511999999999",
  "type": "template",
  "template": {
    "name": "pedido_pronto",
    "language": { "code": "pt_BR" },
    "components": [
      {
        "type": "body",
        "parameters": [
          { "type": "text", "text": "Rafael" },
          { "type": "text", "text": "7539" }
        ]
      }
    ]
  }
}
```

Os `parameters` preenchem as variáveis do template (`{{1}}`, `{{2}}`...) na ordem. Para cabeçalho com mídia e botões dinâmicos, consulte a [referência de mensagens de template da Meta](https://developers.facebook.com/docs/whatsapp/cloud-api/guides/send-message-templates).
