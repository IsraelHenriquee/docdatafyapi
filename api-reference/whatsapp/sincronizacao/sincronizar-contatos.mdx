Quando um número é conectado por [coexistência](/guias/meta/conexao/coexistencia), a agenda de contatos continua apenas no aplicativo do WhatsApp Business, no celular. Esta chamada pede à Meta que envie esses contatos para a sua aplicação.

A resposta apenas confirma o aceite do pedido. **Os dados não vêm nela**: chegam depois, pelo webhook [Contatos sincronizados](/api-reference/whatsapp/webhooks/eventos/contatos-sincronizados), com a agenda na lista `state_sync`.

```json
{
  "messaging_product": "whatsapp",
  "request_id": "7a3b2c1d-e5f6-4a8b-9c0d-1e2f3a4b5c6d",
  "success": true
}
```

<Warning>
  A chamada precisa ser feita em até **24 horas** após a conexão do número. Passado esse prazo, o pedido não tem efeito, e a única forma de recuperar os contatos é desconectar o número e refazer a conexão.
</Warning>

## Antes de chamar

O evento `smb_app_state_sync` precisa estar marcado para a sua URL **antes** do disparo, senão os dados são enviados e não há para onde entregar. No [painel da Datafy](https://app.datafyapi.com.br), na aba **Webhooks** do número, marque `smb_app_state_sync` na URL que vai receber.

```bash
curl -X POST 'https://cloud.datafyapi.com.br/v1/{phone_number_id}/smb_app_data' \
  -H 'Authorization: Bearer sk_live_xxx' \
  -H 'Content-Type: application/json' \
  -d '{ "messaging_product": "whatsapp", "sync_type": "smb_app_state_sync" }'
```

Os contatos podem ser solicitados **uma única vez**. Repetir a chamada não gera um novo envio.

## O que chega

Cada contato chega com nome completo, primeiro nome e número. Na carga inicial todos vêm com a ação `add`. Depois dela, o mesmo evento continua ativo no dia a dia, informando inclusões, edições e remoções feitas no celular. O formato está detalhado em [Contatos sincronizados](/api-reference/whatsapp/webhooks/eventos/contatos-sincronizados).

<Note>
  Guarde o `request_id` da resposta. Ele é o identificador do pedido junto à Meta, necessário caso seja preciso abrir um chamado por dados que não chegaram.
</Note>

As conversas anteriores são solicitadas separadamente, em [Sincronizar histórico](/api-reference/whatsapp/sincronizacao/sincronizar-historico).

O procedimento completo está na [documentação de onboarding da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/embedded-signup/onboarding-business-app-users).
