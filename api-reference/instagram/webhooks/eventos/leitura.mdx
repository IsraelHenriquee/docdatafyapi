---
title: "Confirmação de leitura"
description: "Evento messaging_seen: a pessoa leu as mensagens enviadas."
---

Identificador do evento: **`messaging_seen`**.

Chega em `messaging[]`, identificado pela presença da chave `read`.

```json
{
  "object": "instagram",
  "entry": [
    {
      "id": "17841400000000001",
      "time": 1793200000000,
      "messaging": [
        {
          "sender": { "id": "1000000000000001" },
          "recipient": { "id": "17841400000000001" },
          "timestamp": 1793199998000,
          "read": { "mid": "aWdfZAG1faXRlbTo..." }
        }
      ]
    }
  ]
}
```

O `mid` indica a última mensagem lida. Tudo que foi enviado antes dela também foi lido.

<Note>
  Leitura não reabre a janela de 24 horas. Só mensagem da pessoa faz isso.
</Note>
