Existem **duas formas de conectar um número** à API oficial do WhatsApp pela Datafy. A escolha depende de como esse número é usado hoje.

## Cloud API

Você conecta um número **diretamente à Cloud API**. É o caminho para um número que ainda não está em uso no aplicativo do WhatsApp, como um chip físico ou virtual adquirido para a operação da sua empresa.

## Coexistência

Você conecta o número que **já usa no aplicativo WhatsApp Business** e o vincula à API oficial. Essa forma de conexão é chamada de **coexistência**.
