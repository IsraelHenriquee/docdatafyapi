---
title: "Rotas bloqueadas"
description: "Operações da Meta que não podem ser feitas pela Datafy."
---

Algumas operações alteram configurações que a Datafy gerencia para manter seu número funcionando, como o destino dos webhooks. Por segurança, elas retornam **`403 Forbidden`**:

- Caminhos que contêm `subscribed_apps` ou `deregister`.
- `POST` em um ID com os campos `webhook_configuration` ou `pin`, no corpo ou na URL. Eles alteram o destino dos webhooks e o PIN do número.
- `DELETE` direto no ID do número ou da conta do WhatsApp Business.
- Chamadas de número ou de conta com um ID diferente do que está ligado ao token, como `POST /v1/{outro_phone_number_id}/messages`.

```json
{
  "statusCode": 403,
  "message": "Operação não permitida via proxy"
}
```

Todos os outros endpoints da Meta Cloud API funcionam normalmente. Veja [Outros endpoints da Meta](/api-reference/whatsapp/proxy/outros-endpoints).
