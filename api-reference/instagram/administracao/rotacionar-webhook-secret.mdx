Gera um novo secret para a [assinatura](/api-reference/instagram/webhooks/validar-assinatura) dos webhooks do canal. As próximas entregas já são assinadas com ele.

## Resposta

| Campo | Descrição |
| --- | --- |
| `webhook_secret` | Novo secret dos webhooks do canal |
