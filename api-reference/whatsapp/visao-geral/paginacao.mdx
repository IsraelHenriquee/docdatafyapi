---
title: "Paginação"
description: "Como buscar as próximas páginas de listas, como templates e números."
---

Endpoints que retornam listas, como templates, números e usuários bloqueados, devolvem um objeto `paging`:

```json
"paging": {
  "cursors": { "before": "QVFIU...", "after": "QVFIU..." },
  "next": "https://graph.facebook.com/v25.0/{WABA_ID}/message_templates?limit=25&after=QVFIU..."
}
```

<Warning>
  **Não chame a URL de `paging.next` diretamente.** Ela aponta para a Meta e não funciona sem o token da Meta.
</Warning>

Para buscar a próxima página, repita a mesma chamada na URL da Datafy e acrescente o parâmetro `after` com o valor de `paging.cursors.after`:

```bash
curl "https://cloud.datafyapi.com.br/v1/{WABA_ID}/message_templates?limit=25&after=QVFIU..." \
  -H 'Authorization: Bearer sk_live_xxx'
```

Quando não houver mais páginas, a resposta vem sem `paging.next`.
