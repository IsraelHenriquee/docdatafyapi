## Token do canal

As requisições da API do Instagram usam o token do canal, `sk_live_xxx`, gerado no [painel da Datafy](https://app.datafyapi.com.br) quando você cria o canal. Envie o token **sempre no header** `Authorization`:

```http
Authorization: Bearer sk_live_xxx
```

```bash
curl "https://cloud.datafyapi.com.br/ig/me?fields=username" \
  -H 'Authorization: Bearer sk_live_xxx'
```

A Datafy recebe esse token, identifica o canal e envia a credencial real da Meta por conta própria. O token do Instagram emitido pela Meta nunca chega ao seu código.

## Escopo dos tokens

O token do canal do Instagram vale **apenas** nas rotas `/ig/`, e o token de um número do WhatsApp vale apenas fora delas. Trocar os dois é recusado com `403`.

| Token | Rotas |
| --- | --- |
| `sk_live_` de um canal do Instagram | `/ig/…` |
| `sk_live_` de um número do WhatsApp | `/v1/…` e demais rotas do WhatsApp |
| `sk_acct_` da conta | [Administração](/api-reference/administracao/introducao), em `/channels` |

<Note>
  Os dois tokens de canal têm o mesmo formato. Se uma requisição ao Instagram voltar `403` dizendo que a rota exige token de conta do Instagram, verifique se o token copiado é o do canal certo.
</Note>

## Respostas de autenticação

| Código | Significado |
| --- | --- |
| `401` | Token ausente, inválido ou de um canal que não existe mais |
| `402` | Assinatura da Datafy inativa. Ative no painel para voltar a usar a API |
| `403` | Token do tipo errado para a rota, ou operação não permitida pelo proxy |
| `409` | Canal pausado. Retome o canal para voltar a enviar |

O `402` e o `409` são códigos distintos de propósito: um é problema de cobrança e o outro é uma pausa que você mesmo pediu. Sua integração consegue tratar os dois de formas diferentes sem interpretar texto de mensagem.

## Conectar o canal

O token só funciona depois que a conta do Instagram estiver conectada à Datafy e o canal estiver assinado. A conexão é feita no painel, e exige uma conta **profissional** do Instagram, Empresa ou Criador de conteúdo.

Enquanto o canal não estiver assinado, o token existe mas é recusado com `402`.
