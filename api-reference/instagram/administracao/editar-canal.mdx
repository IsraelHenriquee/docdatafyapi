---
title: "Editar canal"
openapi: "/api-reference/instagram/administracao/specs/canais.json PATCH /channels/instagram/{id}"
---

Envie apenas os campos que mudam. Enviar só `name` ou só `description` mantém o outro como está.

## Resposta

| Campo | Descrição |
| --- | --- |
| `id` | ID do canal |
| `name` | Nome do canal |
| `description` | Descrição do canal |
