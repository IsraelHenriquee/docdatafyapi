Um canal criado pela API nasce sem conta conectada. Esta chamada gera o link que o cliente abre para conectar a conta do Instagram dele ao canal, pelo Business Login da Meta.

## Como usar o link

Gere o link no seu servidor e abra a `url` no navegador do cliente, em uma janela nova:

```js
const janela = window.open(url, 'datafy-instagram', 'width=600,height=760')
```

<Note>
  A janela de conexão pode levar a sua marca. No [painel da Datafy](https://app.datafyapi.com.br/conta), na aba **Parceiros**, é possível definir o logotipo, o nome da empresa e a cor do fundo. A marca é a mesma usada na conexão de WhatsApp.
</Note>

<Warning>
  Gere o link a partir do seu servidor. O token de conta dá acesso a todos os canais e não deve ser exposto no navegador.
</Warning>

## Resultado da conexão

Ao terminar, a janela envia uma mensagem para a página que a abriu, já com os dados da conta conectada:

```js
window.addEventListener('message', (evento) => {
  if (evento.origin !== 'https://app.datafyapi.com.br') return
  if (evento.data?.source !== 'datafy') return

  if (evento.data.event === 'connected') {
    const { ig_user_id, username } = evento.data.data
    // canal conectado
  }

  if (evento.data.event === 'error') {
    // evento.data.message traz o motivo
  }
})
```

| Evento | Conteúdo |
| --- | --- |
| `connected` | `data` com `ig_user_id` e `username` |
| `error` | `message` com o motivo da falha |

Depois do sucesso, a janela se fecha sozinha. Em caso de erro ela permanece aberta, para o cliente tentar de novo.

<Note>
  Os dados da mensagem já bastam para registrar a conexão. Use [Consultar canal](/api-reference/instagram/administracao/consultar-canal) quando precisar dos demais campos, como a foto e o nome do perfil, ou para confirmar a conexão mais tarde.
</Note>

## Validade

O link vale **24 horas** e é de **uso único**: ele deixa de funcionar assim que a conexão é concluída. Para conectar de novo, gere um link novo.

<Note>
  A conta precisa ser **profissional** (Empresa ou Criador de conteúdo). Contas pessoais não aparecem no Business Login.
</Note>

## Resposta

| Campo | Descrição |
| --- | --- |
| `url` | Endereço da página de conexão, para abrir no navegador do cliente |
| `token` | Token do link, já incluído na `url` |
| `expires_in` | Validade do link, em segundos |
