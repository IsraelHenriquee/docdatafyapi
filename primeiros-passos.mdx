<Steps>
  <Step title="Pegue seu token">
    Crie sua conta e seu canal no [painel](https://app.datafyapi.com.br). O token `sk_live_xxx` é gerado automaticamente na criação do canal. Depois, conecte seu número para utilizar a API.
  </Step>
  <Step title="Descubra seus IDs">
    <CodeGroup>

    ```bash cURL
    curl https://cloud.datafyapi.com.br/me \
      -H 'Authorization: Bearer sk_live_xxx'
    ```

    ```javascript Node.js
    const res = await fetch('https://cloud.datafyapi.com.br/me', {
      headers: { Authorization: 'Bearer sk_live_xxx' }
    })
    console.log(await res.json())
    ```

    </CodeGroup>
  </Step>
  <Step title="Envie uma mensagem">
    Abra a aba **API WhatsApp** e teste o endpoint **Enviar mensagem** direto no playground.
  </Step>
</Steps>
