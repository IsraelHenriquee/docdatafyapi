Envia uma mensagem com um **botão que abre uma lista de opções**, organizadas em seções. É ideal quando há mais de três escolhas, como horários disponíveis, produtos de um cardápio ou assuntos do atendimento. A [janela de 24 horas](/api-reference/whatsapp/mensagens/introducao#janela-de-24-horas) precisa estar aberta.

<Note>
  O destinatário pode ser informado pelo **número de telefone** (`to`) ou pelo **ID do usuário** (`recipient`). Se os dois forem enviados, vale o `to`; para enviar pelo ID do usuário, deixe o `to` em branco. Veja a diferença em [Destinatário](/api-reference/whatsapp/mensagens/introducao#destinatário).
</Note>

## Estrutura da mensagem

A mensagem é do tipo `interactive`, com `interactive.type` igual a `list`. O cliente vê o texto e um botão; ao tocar no botão, abre a lista para escolher **uma** opção.

| Parte | Campo | Obrigatório | Limite |
| --- | --- | --- | --- |
| Cabeçalho | `interactive.header.text` | Não | 60 caracteres. Na lista, **só é aceito cabeçalho de texto**. |
| Texto | `interactive.body.text` | **Sim** | 4.096 caracteres. |
| Rodapé | `interactive.footer.text` | Não | 60 caracteres. |
| Botão | `interactive.action.button` | **Sim** | 20 caracteres. É o texto do botão que abre a lista. |
| Seções | `interactive.action.sections` | **Sim** | De 1 a 10 seções. |

## Seções e opções

Cada seção tem um título e suas opções (`rows`):

| Campo | Limite | Para que serve |
| --- | --- | --- |
| `sections[].title` | 24 caracteres | Título que agrupa as opções na lista. |
| `rows[].id` | 200 caracteres | Identificador que **volta no webhook** quando o cliente escolhe a opção. |
| `rows[].title` | 24 caracteres | Texto da opção. |
| `rows[].description` | 72 caracteres | Descrição opcional, exibida abaixo do título. |

<Warning>
  O limite é de **10 opções no total, somando todas as seções**, e não 10 por seção. Uma lista com duas seções, de 6 e 5 opções, é recusada com o erro `131009` ("Total row count exceed max allowed count: 10").
</Warning>

```json
"action": {
  "button": "Ver horários",
  "sections": [
    {
      "title": "Manhã",
      "rows": [
        { "id": "seg-09h", "title": "Segunda, 9h", "description": "Unidade Centro" },
        { "id": "seg-11h", "title": "Segunda, 11h", "description": "Unidade Centro" }
      ]
    },
    {
      "title": "Tarde",
      "rows": [
        { "id": "seg-15h", "title": "Segunda, 15h", "description": "Unidade Norte" }
      ]
    }
  ]
}
```

No **Testar**, a lista já vem preenchida com duas seções de horários. Troque pelas opções do seu atendimento.

## Resposta do cliente

Quando o cliente escolhe uma opção, chega pelo [webhook](/api-reference/whatsapp/webhooks/eventos/mensagens) uma mensagem do tipo `interactive`, com `interactive.type` igual a `list_reply`. O `list_reply.id` é o `id` da opção escolhida, e o `context.id` aponta para a mensagem com a lista:

```json
{
  "object": "whatsapp_business_account",
  "entry": [
    {
      "id": "234567890123456",
      "changes": [
        {
          "value": {
            "messaging_product": "whatsapp",
            "metadata": {
              "display_phone_number": "5541999999999",
              "phone_number_id": "123456789012345"
            },
            "contacts": [
              {
                "profile": {
                  "name": "Camila Souza"
                },
                "wa_id": "5511999999999",
                "user_id": "BR.13491208655302741918"
              }
            ],
            "messages": [
              {
                "context": {
                  "from": "5541999999999",
                  "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNFQjA="
                },
                "from": "5511999999999",
                "from_user_id": "BR.13491208655302741918",
                "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjZDQzM=",
                "timestamp": "1757956500",
                "type": "interactive",
                "interactive": {
                  "type": "list_reply",
                  "list_reply": {
                    "id": "seg-09h",
                    "title": "Segunda, 9h",
                    "description": "Unidade Centro"
                  }
                }
              }
            ]
          },
          "field": "messages"
        }
      ]
    }
  ]
}
```

<Tip>
  Use o `list_reply.id` para identificar a escolha. Um `id` com informação útil, como `seg-09h` ou `produto-123`, evita consultas extras no seu sistema.
</Tip>

A resposta do cliente é uma mensagem nova, então **renova a janela de 24 horas**.

Veja mais detalhes na [documentação de mensagens de lista da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/interactive-list-messages).
