Envia uma mensagem com **até três botões** para o cliente responder com um toque, como **Confirmar**, **Remarcar** e **Cancelar**. É a forma mais simples de coletar uma escolha sem depender de o cliente digitar. A [janela de 24 horas](/api-reference/whatsapp/mensagens/introducao#janela-de-24-horas) precisa estar aberta.

<Note>
  O destinatário pode ser informado pelo **número de telefone** (`to`) ou pelo **ID do usuário** (`recipient`). Se os dois forem enviados, vale o `to`; para enviar pelo ID do usuário, deixe o `to` em branco. Veja a diferença em [Destinatário](/api-reference/whatsapp/mensagens/introducao#destinatário).
</Note>

## Estrutura da mensagem

A mensagem é do tipo `interactive`, com `interactive.type` igual a `button`. Ela tem quatro partes:

| Parte | Campo | Obrigatório | Limite |
| --- | --- | --- | --- |
| Cabeçalho | `interactive.header` | Não | Texto com até 60 caracteres, ou imagem, vídeo ou documento. |
| Texto | `interactive.body.text` | **Sim** | 1.024 caracteres. |
| Rodapé | `interactive.footer.text` | Não | 60 caracteres. |
| Botões | `interactive.action.buttons` | **Sim** | De 1 a 3 botões. |

## Botões

Cada botão tem `type` igual a `reply` e um objeto `reply` com dois campos:

| Campo | Limite | Para que serve |
| --- | --- | --- |
| `reply.id` | 256 caracteres | Identificador que **volta no webhook** quando o cliente toca no botão. Use um valor que o seu sistema reconheça, como `confirmar` ou `pedido-7539-cancelar`. |
| `reply.title` | 20 caracteres | Texto exibido no botão. **Não pode se repetir** entre os botões da mesma mensagem. |

```json
"action": {
  "buttons": [
    { "type": "reply", "reply": { "id": "confirmar", "title": "Confirmar" } },
    { "type": "reply", "reply": { "id": "remarcar", "title": "Remarcar" } },
    { "type": "reply", "reply": { "id": "cancelar", "title": "Cancelar" } }
  ]
}
```

## Cabeçalho

O cabeçalho é opcional e aceita um texto ou uma mídia:

| `header.type` | Conteúdo |
| --- | --- |
| `text` | `header.text`, com até 60 caracteres. |
| `image` | `header.image`, com `link` ou `id`. |
| `video` | `header.video`, com `link` ou `id`. |
| `document` | `header.document`, com `link` ou `id`. |

A mídia do cabeçalho segue as mesmas regras e formatos de [Enviar imagem](/api-reference/whatsapp/mensagens/enviar-imagem), [Enviar vídeo](/api-reference/whatsapp/mensagens/enviar-video) e [Enviar documento](/api-reference/whatsapp/mensagens/enviar-documento): informe `link` **ou** `id`, nunca os dois.

```json
"header": {
  "type": "image",
  "image": { "link": "https://exemplo.com/agenda.jpg" }
}
```

No **Testar**, a mensagem já vem preenchida com um cabeçalho de texto, o texto, o rodapé e três botões. Para testar um cabeçalho com mídia, troque o `type` do cabeçalho e preencha o `link` da mídia.

## Resposta do cliente

Quando o cliente toca em um botão, chega pelo [webhook](/api-reference/whatsapp/webhooks/eventos/mensagens) uma mensagem do tipo `interactive`, com `interactive.type` igual a `button_reply`. O `button_reply.id` é o `reply.id` do botão tocado, e o `context.id` aponta para a mensagem com os botões:

```json
{
  "object": "whatsapp_business_account",
  "entry": [
    {
      "id": "234567890123456",
      "changes": [
        {
          "value": {
            "messaging_product": "whatsapp",
            "metadata": {
              "display_phone_number": "5541999999999",
              "phone_number_id": "123456789012345"
            },
            "contacts": [
              {
                "profile": {
                  "name": "Camila Souza"
                },
                "wa_id": "5511999999999",
                "user_id": "BR.13491208655302741918"
              }
            ],
            "messages": [
              {
                "context": {
                  "from": "5541999999999",
                  "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNFQjA="
                },
                "from": "5511999999999",
                "from_user_id": "BR.13491208655302741918",
                "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjVBQjI=",
                "timestamp": "1757956200",
                "type": "interactive",
                "interactive": {
                  "type": "button_reply",
                  "button_reply": {
                    "id": "confirmar",
                    "title": "Confirmar"
                  }
                }
              }
            ]
          },
          "field": "messages"
        }
      ]
    }
  ]
}
```

<Tip>
  Use o `button_reply.id` para decidir o que fazer com a resposta. O `title` pode mudar se você ajustar o texto do botão; o `id` continua o mesmo.
</Tip>

A resposta do cliente é uma mensagem nova, então **renova a janela de 24 horas**.

Veja mais detalhes na [documentação de botões de resposta da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/interactive-reply-buttons-messages).
