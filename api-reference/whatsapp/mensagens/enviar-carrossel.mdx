Envia um **carrossel de cartões** que o cliente rola para o lado. Cada cartão tem uma imagem ou um vídeo, um texto curto e um botão. É ideal para apresentar produtos, planos ou opções lado a lado. A [janela de 24 horas](/api-reference/whatsapp/mensagens/introducao#janela-de-24-horas) precisa estar aberta.

<Note>
  O destinatário pode ser informado pelo **número de telefone** (`to`) ou pelo **ID do usuário** (`recipient`). Se os dois forem enviados, vale o `to`; para enviar pelo ID do usuário, deixe o `to` em branco. Veja a diferença em [Destinatário](/api-reference/whatsapp/mensagens/introducao#destinatário).
</Note>

## Estrutura da mensagem

A mensagem é do tipo `interactive`, com `interactive.type` igual a `carousel`:

| Parte | Campo | Obrigatório | Limite |
| --- | --- | --- | --- |
| Texto | `interactive.body.text` | **Sim** | 1.024 caracteres. Aparece acima dos cartões. |
| Cartões | `interactive.action.cards` | **Sim** | De **2 a 10** cartões. |

O carrossel **não aceita cabeçalho nem rodapé** no nível da mensagem. A mídia e os botões ficam dentro de cada cartão.

## Cartões

Cada item de `cards` é um cartão:

| Campo | Obrigatório | Regra |
| --- | --- | --- |
| `card_index` | **Sim** | Posição do cartão, começando em `0` e indo até `9`. |
| `type` | **Sim** | Use `cta_url`, inclusive nos cartões com botões de resposta rápida. Sem esse campo, a Meta recusa o envio. |
| `header` | **Sim** | Imagem ou vídeo do cartão, **somente por `link`**. |
| `body.text` | Não | Texto do cartão, com até **160 caracteres** e no máximo 2 quebras de linha. |
| `action` | **Sim** | Um botão com link **ou** botões de resposta rápida. |

<Warning>
  Todos os cartões precisam ser **iguais na estrutura**: o mesmo tipo de mídia (só imagens ou só vídeos) e o mesmo tipo e quantidade de botões. Se um cartão tem dois botões de resposta rápida, todos precisam ter dois.
</Warning>

### Mídia do cartão

A mídia do cartão fica em `header`, com `type` igual a `image` ou `video`, e só é aceita por **`link`**:

```json
"header": {
  "type": "image",
  "image": { "link": "https://exemplo.com/produto-1.jpg" }
}
```

<Warning>
  O carrossel **não aceita o `id` de mídia** no cartão. Com `header.image.id`, a Meta recusa o envio com o erro `131009` ("The parameter interactive['action']['cards'][].header.image.link is required"). Para gerar um link, envie o arquivo na aba **Mídias** do número, no [painel da Datafy](https://app.datafyapi.com.br).
</Warning>

Os formatos e tamanhos aceitos são os mesmos de [Enviar imagem](/api-reference/whatsapp/mensagens/enviar-imagem#formatos-aceitos) e [Enviar vídeo](/api-reference/whatsapp/mensagens/enviar-video#formatos-aceitos).

### Botão com link

Para um botão que abre uma URL, use `name` igual a `cta_url` e os `parameters`:

```json
{
  "card_index": 0,
  "type": "cta_url",
  "header": {
    "type": "image",
    "image": { "link": "https://exemplo.com/produto-1.jpg" }
  },
  "body": { "text": "*Cesta de frutas*\nFrutas frescas selecionadas." },
  "action": {
    "name": "cta_url",
    "parameters": {
      "display_text": "Comprar",
      "url": "https://exemplo.com/produto-1"
    }
  }
}
```

`display_text` aceita até **20 caracteres**. A URL abre no navegador do celular e não aparece no cartão.

### Botões de resposta rápida

Para o cliente responder com um toque, use `action.buttons` com itens do tipo `quick_reply`:

```json
{
  "card_index": 0,
  "type": "cta_url",
  "header": {
    "type": "image",
    "image": { "link": "https://exemplo.com/produto-1.jpg" }
  },
  "body": { "text": "*Cesta de frutas*\nFrutas frescas selecionadas." },
  "action": {
    "buttons": [
      {
        "type": "quick_reply",
        "quick_reply": { "id": "cesta-frutas-saber-mais", "title": "Saber mais" }
      },
      {
        "type": "quick_reply",
        "quick_reply": { "id": "cesta-frutas-favoritar", "title": "Favoritar" }
      }
    ]
  }
}
```

| Campo | Limite | Para que serve |
| --- | --- | --- |
| `quick_reply.id` | 256 caracteres | Identificador do botão. Inclua algo que identifique o cartão, como `cesta-frutas-saber-mais`, para saber qual produto o cliente escolheu. |
| `quick_reply.title` | 20 caracteres | Texto exibido no botão. |

<Note>
  Nos cartões com botões de resposta rápida, o `type` do cartão continua sendo `cta_url`, como no exemplo da Meta. O valor `quick_reply` não é aceito nesse campo.
</Note>

No **Testar**, o carrossel já vem preenchido com três cartões de exemplo com botão de link. Para testar botões de resposta rápida, troque o `action` de cada cartão pelo formato acima.

## Resposta do cliente

Quando o cliente toca em um botão de **resposta rápida** de um cartão, chega pelo [webhook](/api-reference/whatsapp/webhooks/eventos/mensagens) uma mensagem do tipo **`button`**, com o `id` do botão em `button.payload` e o rótulo em `button.text`. O `context.id` aponta para a mensagem do carrossel:

```json
{
  "object": "whatsapp_business_account",
  "entry": [
    {
      "id": "234567890123456",
      "changes": [
        {
          "value": {
            "messaging_product": "whatsapp",
            "metadata": {
              "display_phone_number": "5541999999999",
              "phone_number_id": "123456789012345"
            },
            "contacts": [
              {
                "profile": {
                  "name": "Camila Souza"
                },
                "wa_id": "5511999999999",
                "user_id": "BR.13491208655302741918"
              }
            ],
            "messages": [
              {
                "context": {
                  "from": "5541999999999",
                  "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjNFQjA="
                },
                "from": "5511999999999",
                "from_user_id": "BR.13491208655302741918",
                "id": "wamid.HBgNNTUxMTk5OTk5OTk5ORUCABIYFjdEQjQ=",
                "timestamp": "1757956800",
                "type": "button",
                "button": {
                  "payload": "cesta-frutas-saber-mais",
                  "text": "Saber mais"
                }
              }
            ]
          },
          "field": "messages"
        }
      ]
    }
  ]
}
```

<Warning>
  O carrossel é diferente de [Enviar botões](/api-reference/whatsapp/mensagens/enviar-botoes). Lá a resposta chega como `interactive`, com `interactive.button_reply.id`. Aqui ela chega como `button`, com `button.payload`. Se o seu sistema só trata `button_reply`, os toques no carrossel passam despercebidos.
</Warning>

Como o `payload` é o único dado que identifica a escolha, use um `id` que diga **qual cartão e qual ação**, como `cesta-frutas-saber-mais`.

Cartões com **botão de link** não geram webhook quando o cliente toca. Para medir esses cliques, use um parâmetro de rastreamento na URL.

A resposta do cliente é uma mensagem nova, então **renova a janela de 24 horas**.

Veja mais detalhes na [documentação de carrossel de mídia da Meta](https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/interactive-media-carousel-messages).
