---
title: "Listar comentários"
description: "Liste os comentários de uma publicação."
openapi: "/api-reference/instagram/specs/comentarios-listar.json GET /ig/{media_id}/comments"
---

Retorna os comentários de uma publicação da própria conta, do mais recente para o mais antigo.

O `media_id` vem de `GET /ig/me/media`.

## Campos

Nenhum campo além do `id` é devolvido por padrão. Liste em `fields`, separados por vírgula, os campos que você precisa:

```
fields=id,text,timestamp,like_count,hidden,from
```

<Warning>
  Para saber quem comentou, inclua **`from`** na lista de `fields`. O campo `username` de primeiro nível não é devolvido para comentários de terceiros.
</Warning>

O campo `hidden` indica se o comentário está oculto na publicação. Ele continua aparecendo na listagem mesmo oculto.

## Respostas de um comentário

As respostas não vêm na listagem principal. Para obtê-las, chame o mesmo endpoint no ID do comentário:

```bash
curl "https://cloud.datafyapi.com.br/ig/{comment_id}/replies?fields=id,text,from" \
  -H 'Authorization: Bearer sk_live_xxx'
```

Comentário sem respostas devolve `{"data":[]}`.
